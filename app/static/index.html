Frontend Integration Examples

Call the API directly from your React, Vue, Next.js, Flutter, or mobile app:

JavaScript / TypeScript (Fetch API):

// Send chat query to Construction Agent
const response = await fetch("http://localhost:8000/api/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    messages: [
      { role: "user", content: "Estimate steel rods for 1500 sqft G+1 house" }
    ],
    model: "llama-3.3-70b-versatile" // or leave default
  })
});
const data = await response.json();
console.log(data.reply);
console.log("Structured Tools Result:", data.structured_results);

Flutter / Dart:

final res = await http.post(
  Uri.parse('http://localhost:8000/api/estimate/residential'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({
    'built_up_area_sqft': 1500,
    'floors': 2,
    'seismic_zone_v': true
  }),
);
final Map<String, dynamic> estimate = jsonDecode(res.body);
print("Total 12m Rods: ${estimate['rebar_breakdown']['total_standard_12m_rods']}");
